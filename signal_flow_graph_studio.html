Help and walkthrough

This built-in guide explains the full workflow: build a graph, shape it, zoom and scroll large layouts, rename nodes, edit branch gains, solve with Mason’s formula, evaluate numerically, and export your work.

Quick reference poster: add nodes, draw branches and self-loops, drag branch handles, zoom and scroll large graphs, edit node names and branch gains, solve with Mason’s rule, evaluate numerically, and export results.

Quick start

  1. Choose Add Node, then click the workspace to place nodes.
  2. Choose Add Branch, click the start node, then the end node.
  3. For a self-loop, click the same node twice while in Add Branch mode.
  4. Use Select to drag nodes and branch handles.
  5. Pick start and end nodes, then click Solve (Mason).

Navigation

  • Use the zoom buttons in the top-right toolbar.
  • Use Fit to fit the current graph into the viewport.
  • Hold Ctrl and use the mouse wheel to zoom at the current view center.
  • Use the scrollbars in the canvas area to navigate larger graphs.

Editing and shaping

  • Click a node or branch in Select mode, then use the right-side inspector to rename the node or update the branch gain.
  • Single-click or double-click a branch label on the canvas to edit it directly.
  • In Select mode, click a node or branch to manage it from the right-side inspector.
  • Drag the small branch handle to reshape curved branches or self-loops.
  • Use Duplicate node, Reverse branch, or Reset curve from the right panel.

Solving, saving, and exporting

  • The bottom panel lists forward paths, loops, Δ, and the overall transfer function.
  • Enter values like G1=5, G2=0.3, H=0.2 to evaluate the symbolic answer numerically.
  • Use Export JSON or Import JSON to move graphs between sessions.
  • Use Export PNG for image output.
  • The app also autosaves the current graph locally in your browser.

Keyboard shortcuts

  • A Add Node
  • B Add Branch
  • S Select
  • D Delete
  • Delete Remove the selected item
  • Ctrl + S Save locally
